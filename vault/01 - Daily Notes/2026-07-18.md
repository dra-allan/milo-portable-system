## Session 8 — 00:45+: obsidian-web View Overhaul

### What Got Done
- **2D graph crash fixed** — removed `graph.nodeVisibility()` ref call (wasn't a function on mount). Replaced with data-side filtering: when searchTerm changes, we filter graphData nodes/links before passing as prop instead of calling `.nodeVisibility()` on the ForceGraph2D instance. Cleaner, no timing issues.
- **Double-click everywhere** — `onNodeClick` → `onNodeDoubleClick` / `onDoubleClick` in GraphView2D, GraphView3D, Constellation (was Radial), Wave Timeline (was Timeline), and Canvas view. Single click now does nothing except Select/Connect mode interaction in Canvas.
- **Floating canvas notes** — RAF animation loop applies gentle sinusoidal drift (sin/cos at different frequencies per node) to each ReactFlow node's position. Drift suspends during drag (`draggingIds` tracked) and resumes when dropped with updated base position.
- **Radial → Constellation** — replaced d3 cluster dendrogram with d3 force-directed layout. Nodes connected by wiki-links settle into organic clusters. Draggable. Double-click opens note.
- **Timeline → Wave Strand** — replaced flat timeline with sine-wave strand path. Notes positioned along curve by date. Wiki-link relations shown as translucent arcs above the strand. Tooltip on hover. Double-click to open.
- **3D → Brain** — nodes pre-positioned in two-hemisphere layout. Rendered as THREE.js neuron spheres (PhongMaterial + emissive glow + outer glow shell). Traveling signal particles on links via `linkDirectionalParticles={2}`. Labels hidden until camera zoomed in past threshold (`globalScale > 1.8` in `nodeCanvasObject`).
- **Build clean** — `npm run build` passes (tsc + vite). 3.1MB JS bundle (dominated by three.js + react-flow).

### What's Still In Progress
- Canvas drag-from-sidebar (FileSystemHandle integration)
- Mobile/responsive polish

### Decisions Made
- react-force-graph-2d: use data-side filtering over `.nodeVisibility()` ref method — avoids mount-timing TIFU entirely.
- Brain layout: initial coordinates in two clusters (left/right hemisphere) so the force simulation settles into a brain-like shape naturally rather than fighting a random start.
- Three.js for custom neurons with sprite glow was too heavy; used MeshPhongMaterial + emissive + transparent outer glow sphere instead — renders well without shader complexity.
- RAF floating at ~2.5px amplitude is subtle enough to feel alive without interfering with node interaction.
